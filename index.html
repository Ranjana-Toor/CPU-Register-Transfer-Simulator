LEARN THE BASICS

Help & Instructions

01

Registers

Registers are small, fast storage locations inside the CPU. This simulator has four 8-bit registers, R0 to R3.

02

RTL notation

Register Transfer Language describes data movement. The arrow ← means the value on the right is copied into the register on the left.

03

8-bit wraparound

Values are stored modulo 256. For example, 255 + 1 becomes 0 (overflow), and 0 − 1 becomes 255 (underflow).

04

Logical operations

AND sets a bit when both inputs have it; OR when either input has it; XOR when inputs differ; NOT flips every bit.
